ZohoBoil v0.1 — first public release

I built ZohoBoil because I kept hand-animating wobble onto clean digital footage and getting tired of doing it frame-by-frame in After Effects. There are plug-ins that approximate it, but they cost real money and they all look... synthetic. I wanted something free, fast, and ugly in the right way.

Today's the first public release. It's a Mac app. You download it, drag it to Applications, drop a video on it, and you get the wobbly, hand-drawn look that modern digital animation forgot.

What's in v0.1

  • Line boil — edge-aware random displacement with five edge-blend modes (chunky, smooth, linear, hard, gentle).
  • Chromatic aberration — independent R/G/B channel offsets plus a CA Blur for softness.
  • Animated noise overlays — fine grain, medium, coarse, TV static, Perlin (three scales), scanlines.
  • Edge detection in LAB color space, so the boil catches color transitions that grayscale Sobel would miss.
  • Live preview with frame scrubbing and animated playback while you drag sliders.
  • Audio preserved on export. H.264 MP4 out, ready for the web.
  • GIF support — drop a GIF, it auto-loops to 5 seconds and processes like a video.

What's not in v0.1

Honest list, so nobody expects something they won't get:

  • No Windows or Linux build. Mac only. macOS 12+ on Apple Silicon. Intel Mac and Windows builds are on the roadmap but not promised.
  • Not code-signed. First launch needs a right-click → Open to bypass the Gatekeeper warning. Code signing requires the $99/yr Apple Developer Program and isn't worth it yet for a free open-source tool. (Donations toward it accepted.)
  • No GPU acceleration. Everything runs on CPU via OpenCV. A 1080p, 30-second clip processes in under a minute on an M2; longer clips and 4K take proportionally longer.
  • No web version. Server costs and the file-upload bandwidth math don't make sense for a free tool yet. Maybe later, if there's demand.

How it works under the hood

For each frame, ZohoBoil:

  1. Converts to LAB color space and runs Sobel edge detection on each channel, taking the max to build a single edge-strength map.
  2. Generates N pre-baked random displacement maps (the "variations"). Each one is a low-resolution grid of random vectors, upscaled with one of five interpolation strategies to control how blocky vs. smooth the wobble feels.
  3. Cycles through those variations every hold-frames frames, so the boil "holds" briefly before shifting — the same way a hand-drawn animator holds each drawing for a few frames.
  4. Weights the displacement by the edge map, so the wobble concentrates on edges (or doesn't, depending on your Edge Weight slider).
  5. Applies the displacement via cv2.remap, then layers on chromatic aberration and noise overlays.
  6. Re-encodes the output to H.264 via a bundled ffmpeg binary, copying the original audio track through.

The full source is open under the MIT license: github.com/princezoho/zohoboil. Fork it, modify it, ship your own version. Just keep the copyright line.

What's next

Roadmap in roughly the order I plan to ship it:

  • Better presets (one-click "VHS", "rotoscope", "Saturday morning cartoon")
  • Universal binary so it runs natively on Intel Macs too
  • Per-region masks — boil just the character, leave the background still
  • Windows build
  • Tempo-locked boil — sync the variation cycle to a BPM for music videos

If you use ZohoBoil and something is broken or stupid, open an issue on GitHub. If you ship something cool made with it, send it.
